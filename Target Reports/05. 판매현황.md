# 판매현황 (Full-year Sales Status)

Monthly accumulation of sales data across the year. Comprehensive sales and inventory tracking.

## Sheet Structure

**Tabs:**
- **판매현황(화성)** — Sales status (detailed transactions)
- **ㅍ** — Summary by item code and month
- **재고현황** — Inventory status snapshot
- **미판매현황** — Unsold status (ordered but not delivered)
- **미입고현황** — Unreceived status (ordered but not received)
- **자료** — Data/Materials
- **data** — Data

## Tab 1: 판매현황(화성) (Sales Status)

**Purpose:** Detailed transaction-level ledger showing every sale. Each row represents a single transaction with full customer, product, pricing, and warehouse details.

**Columns:**
1. 월 — Month
2. 일자 — Date
3. 거래처그룹1코드명 — Customer Group 1 Code Name
4. 세무신고거래처코드 — Tax Report Customer Code
5. 거래처코드 — Customer Code
6. 담당자코드명 — Manager Code Name
7. 판매처명 — Sales Customer Name
8. 품목코드 — Item Code
9. 품목명(규격) — Item Name (Specification)
10. 단위 — Unit
11. 규격명 — Specification Name
12. 수량 — Quantity
13. 중량 — Weight
14. 단가 — Unit Price
15. 공급가액 — Supply Amount
16. 합계 — Total
17. 품목그룹1코드 — Item Group 1 Code
18. 품목그룹2명 — Item Group 2 Name
19. 품목그룹3코드 — Item Group 3 Code
20. 창고명 — Warehouse Name
21. 거래처그룹2명 — Customer Group 2 Name
22. 적요 — Description/Notes
23. 적요 — Description/Notes (second field)
24. 실납업체 — Actual Delivery Company

## Tab 2: ㅍ (Summary)

**Purpose:** Aggregated summary view by item code and month. Provides quick totals without transaction-level detail.

**Columns:**
- 품목코드 — Item Code
- 월 — Month (numeric)
- 합계 — Total

## Tab 3: 재고현황 (Inventory Status)

**Purpose:** Inventory snapshot as of a specific date. Shows what stock is on hand with valuation.

**Header:**
- 회사명: (주)영일오엔씨 / 화성 / {date} / 재고현황

**Columns:**
1. 품목코드 — Item Code
2. 품명 및 규격 — Item Name and Specification
3. 단위 — Unit
4. 재고수량 — Inventory Quantity
5. 중량 — Weight
6. 화성 — Hwaseong (branch/location)
7. 입고단가 — Incoming Unit Price
8. 금액 — Amount (valuation)
9. 품목그룹1명 — Item Group 1 Name
10. 품목그룹2명 — Item Group 2 Name
11. 품목그룹3명 — Item Group 3 Name
12. 석유류 — Petroleum Category

## Tab 4: 미판매현황 (Unsold Status)

**Purpose:** Tracks products that were ordered by customers but not yet sold/delivered. Helps management see outstanding orders and backlog.

**Header:**
- 회사명: (주)영일오엔씨 / 화성 / {start date} ~ {end date}

**Columns:**
1. 월/일 — Month/Day
2. 품목코드 — Item Code
3. 품명 및 규격 — Item Name and Specification
4. 수량 — Quantity (ordered)
5. 잔량 — Remaining Quantity (not yet delivered)
6. 공급가액 — Supply Amount
7. 거래처명 — Customer Name
8. 적요 — Description/Notes
9. 납기일자 — Delivery Date

**Grouping:** Data is grouped monthly with 총합계 (total sum) for each month.

## Tab 5: 미입고현황 (Unreceived Status)

**Purpose:** Tracks products that were ordered from suppliers but not yet received. Shows incoming inventory pipeline and purchase orders in progress.

**Header:**
- 회사명: (주)영일오엔씨 / 화성 / {start date} ~ {end date}

**Columns:**
1. 월/일 — Month/Day
2. 품목코드 — Item Code
3. 품명 및 규격 — Item Name and Specification
4. 수량 — Quantity (ordered)
5. 잔량 — Remaining Quantity (not yet received)
6. 잔량(중량) — Remaining Quantity (Weight)
7. 미구매공급가액 — Unpurchased Supply Amount
8. 미구매부가세 — Unpurchased VAT
9. 합계 — Total (supply amount + VAT)
10. 납기일자 — Delivery Date
11. 거래처명 — Supplier Name
12. 품목그룹1명 — Item Group 1 Name
13. 창고명 — Warehouse Name
14. 품목별납기일자 — Item-specific Delivery Date

## Tab 6: 자료 (Data)

**Purpose:** Master summary table aggregating monthly data across the year with cross-references to other report sections.

**Columns:**
1. 모빌코드 — Mobil Code
2. 품목코드 — Item Code
3. 품목코드 — Item Code (duplicate)
4. 품명 및 규격 — Item Name and Specification
5. 단위 — Unit
6. 규격명 — Specification Name
7-18. Monthly columns: 1월 ~ 12월 (January through December, first period)
19-29. Monthly columns: 1월 ~ 11월 (January through November, second period)
30. 미판매 — Unsold
31. 재고현황 — Inventory Status
32. 미입고현황 — Unreceived Status

This tab provides a consolidated year-over-year view by item, with monthly totals and links to related status reports.

## Tab 7: data

**Note:** This tab contains raw ERP system download data and can be ignored for reporting purposes.

---

This comprehensive file combines transaction detail (판매현황), summary views (ㅍ), current inventory position (재고현황), customer order backlog (미판매현황), and supplier order pipeline (미입고현황) — giving management a complete picture of sales, stock, and order flow.
