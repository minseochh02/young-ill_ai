# 장기재고현황 (Long-term Inventory by Branch)

Flags slow-moving stock. Reviewed weekly or before month-end.

## Sheet Structure

**Tabs (by branch):**
- 화성
- 창원
- 동부
- 서부
- 제주

## Data Structure

**Purpose:** Identifies slow-moving or stagnant inventory at each branch. Lists specific products with their previous month's inventory levels, helping management identify which items need clearance, promotion, or ordering adjustments.

**Columns:**
- 구분 — Division/Category
- 제품명 — Product name (specific brand names)
- 규격 — Specification/Size (unit types: DM, PL, BOX, EA)
- {month} 전재고 — Previous month inventory

**Unit types in 규격:**
- **DM** — Drum
- **PL** — Pail
- **BOX** — Box
- **EA** — Each (individual unit)

This granular product-level view allows management to see exactly which products are not moving, down to the package type. The specification column distinguishes between different container sizes or formats of the same product.
