# 엑셀 시트 자동 병합기

같은 이름으로 시작하는 엑셀 파일들을 날짜 역순으로 자동 병합해주는 애플리케이션입니다.

## 주요 기능

- **자동 파일 그룹화**: 파일명 접두어를 기준으로 자동 그룹화
- **날짜 역순 정렬**: 최신 파일이 항상 위로 오도록 정렬
- **실시간 감시**: 새 파일 추가 시 자동 병합 (자동 모드)
- **GUI 인터페이스**: 사용하기 쉬운 그래픽 인터페이스
- **다양한 포맷 지원**: .xlsx, .xls, .csv 파일 지원

## 설치 방법

```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
python main.py
```

## 사용법

1. **감시 폴더 선택**: 엑셀 파일들이 있는 폴더를 선택합니다.
2. **출력 폴더 선택**: 병합된 파일이 저장될 폴더를 선택합니다.
3. **파일 스캔**: 현재 폴더의 파일들을 스캔하여 그룹을 확인합니다.
4. **병합 실행**: 수동으로 병합을 실행하거나 자동 모드를 사용할 수 있습니다.

## 파일명 규칙

파일명에 `년월일시분초` 형식의 날짜 정보가 포함되어야 합니다.

예시:
- `보고서_20240115143022.xlsx`
- `데이터_20240115142530.csv`
- `리포트_20240115142000.xls`

## 자동 모드

자동 모드를 활성화하면:
- 새 파일이 추가되면 자동으로 감지
- 2초 디바운스로 중복 실행 방지
- 실시간으로 병합 결과 확인

## 출력 형식

병합된 파일에는 다음 정보가 추가됩니다:
- `source_file`: 원본 파일명
- `file_datetime`: 파일 datetime 정보
- `import_order`: 가져온 순서
